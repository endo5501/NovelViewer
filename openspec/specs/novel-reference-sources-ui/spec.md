## Purpose

ファイルブラウザから小説の参照元を確認・編集する UI を定める。解析で実際に読まれる範囲と、編集が及ぶ範囲をユーザーが一望できるようにする。

## Requirements

### Requirement: 「参照元の設定...」メニュー項目

ファイルブラウザで登録済み小説フォルダのコンテキストメニュー（右クリック、タッチでは長押し）を開いたとき、メニューに「参照元の設定...」項目を含めなければならない（SHALL）。整理フォルダのメニューには含めてはならない（SHALL NOT）。

LLM要約が使えない環境では、この項目を表示してはならない（SHALL NOT）。判定は、解析開始の項目の出し分けと同じ条件で行う。

この項目を選ぶと、その小説の参照元管理ダイアログを開かなければならない（SHALL）。

文言は en / ja / zh の `.arb` にすべて存在しなければならない（SHALL）。

#### Scenario: 小説フォルダのメニューに表示される
- **WHEN** LLM要約が使える環境で、登録済み小説フォルダを右クリックする
- **THEN** メニューに「参照元の設定...」が表示される

#### Scenario: 整理フォルダには表示されない
- **WHEN** 整理フォルダを右クリックする
- **THEN** メニューに「参照元の設定...」は表示されない

#### Scenario: LLM要約が使えない環境では表示されない
- **WHEN** LLM要約が使えない環境で、登録済み小説フォルダを右クリックする
- **THEN** メニューに「参照元の設定...」は表示されない

### Requirement: 参照元管理ダイアログ

参照元管理ダイアログは、対象の小説のタイトルを見出しに示し、次の3つの区画を表示しなければならない（SHALL）。

1. 直接の参照元：対象の小説が直接参照する小説の一覧。各行に削除の操作を持つ。区画には参照元を追加する操作を置く。
2. 祖先から含まれるもの（読み取り専用）：直接の参照元ではないが、祖先としてたどられる小説の一覧。各行に、どの直接の参照元を経由して含まれるかを示す。
3. この作品を参照している作品（読み取り専用）：対象の小説を直接の参照元とする小説の一覧。

各小説はタイトルで表示しなければならない（SHALL）。webコレクションには、その種類が分かる表示を添えなければならない（SHALL）。

ダイアログ内での追加・削除は、「保存」を選ぶまで永続化してはならない（SHALL NOT）。「キャンセル」を選ぶかダイアログを閉じた場合、関係は開く前の状態のまま変わってはならない（SHALL NOT）。「祖先から含まれるもの」の区画は、編集中の内容に基づいて表示を更新しなければならない（SHALL）。

#### Scenario: 3つの区画が表示される
- **WHEN** 『第3部』の参照元が『第2部』、『第2部』の参照元が『第1部』、『外伝』の参照元が『第3部』のとき、『第3部』のダイアログを開く
- **THEN** 直接の参照元に『第2部』が表示される
- **AND** 祖先から含まれるものに『第1部』が「第2部 経由」として表示される
- **AND** この作品を参照している作品に『外伝』が表示される

#### Scenario: キャンセルすると変更は破棄される
- **WHEN** ダイアログで直接の参照元を1件削除し、「キャンセル」を選ぶ
- **THEN** 関係は変わらない

#### Scenario: 保存すると変更が永続化される
- **WHEN** ダイアログで参照元を1件追加し、「保存」を選ぶ
- **THEN** その関係が保存され、次にダイアログを開いたとき直接の参照元に表示される

### Requirement: 参照元の選択ダイアログ

参照元を追加する操作は、登録済み小説を選ぶダイアログを開かなければならない（SHALL）。候補には、整理フォルダの配下にあるものを含め、ライブラリ内の登録済み小説をタイトルで並べなければならない（SHALL）。候補はタイトルの部分一致で絞り込めなければならない（SHALL）。

次のものは、候補に含めてはならない（SHALL NOT）。

- 対象の小説自身
- 対象の小説の子孫（対象の小説を祖先に持つ小説。選ぶと循環になる）
- 編集中の時点で、すでに直接の参照元であるもの

#### Scenario: 循環になる候補は表示されない
- **WHEN** 『外伝』の参照元が『第3部』のとき、『第3部』の選択ダイアログを開く
- **THEN** 候補に『第3部』と『外伝』は表示されない

#### Scenario: タイトルで絞り込める
- **WHEN** 選択ダイアログの検索欄に「Wiki」と入力する
- **THEN** タイトルに「Wiki」を含む候補だけが表示される
