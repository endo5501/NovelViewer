## Purpose

speech.cpp の C API を Dart から呼ぶための最小限の FFI バインディングについて、ライブラリの見つけ方、ライブラリが無いときの案内、オプションの指定方法、合成と中断、エラーの伝え方を定める。

## Requirements

### Requirement: プラットフォームごとのライブラリ名

バインディングは、iOS では `speech_cpp.framework/speech_cpp` を開かなければならない (MUST)。speech.cpp のライブラリを用意していないプラットフォームでは、ライブラリ名を求めたときに、未対応であることを示すエラーを返さなければならない (MUST)。

#### Scenario: iOS のライブラリ名
- **WHEN** iOS 向けのライブラリ名を求める
- **THEN** `speech_cpp.framework/speech_cpp` が返る

#### Scenario: 未対応のプラットフォーム
- **WHEN** speech.cpp のライブラリを用意していないプラットフォームのライブラリ名を求める
- **THEN** 未対応であることを示すエラーになる

### Requirement: ライブラリが無いときはビルド手順を案内する

ライブラリを開けなかったとき、バインディングは、開こうとしたライブラリ名と、それを作るビルドスクリプト（iOS では `scripts/build_speech_ios.sh`）を含むエラーを返さなければならない (MUST)。

#### Scenario: iOS で framework が無い
- **WHEN** 存在しない framework を iOS 向けの手順で開こうとする
- **THEN** 開こうとしたライブラリ名と `scripts/build_speech_ios.sh` を含むエラーになる

### Requirement: リクエストのオプションは名前で指定する

バインディングは、リクエストのオプション（`voice`、`seed` など）を名前で受け取り、speech.cpp が実行時に返す識別子に変換して渡さなければならない (MUST)。オプションの識別子の数値を Dart 側に固定してはならない (MUST NOT)。speech.cpp の版によって番号が変わりうるからである。speech.cpp が知らない名前を渡したときは、その名前を含むエラーを返さなければならない (MUST)。

#### Scenario: 知っている名前のオプション
- **WHEN** `voice` オプションに値を設定する
- **THEN** speech.cpp が `voice` に対して返した識別子で、値がリクエストに設定される

#### Scenario: 知らない名前のオプション
- **WHEN** speech.cpp が知らない名前のオプションを設定する
- **THEN** その名前を含むエラーになり、リクエストは変更されない

### Requirement: エラーは状態名と詳細を伴って報告する

speech.cpp の関数が失敗を示す状態を返したとき、バインディングは、状態の名前と、speech.cpp が返したエラーの詳細を含むエラーを返さなければならない (MUST)。

#### Scenario: モデルの読み込みに失敗する
- **WHEN** 存在しないモデルファイルを読み込む
- **THEN** 失敗を示す状態の名前と、speech.cpp のエラーの詳細を含むエラーになる

### Requirement: 合成は音声の全サンプルとサンプルレートを返す

合成は、speech.cpp が渡したサンプルを順に連結した音声全体と、モデルのサンプルレートを返さなければならない (MUST)。中断されたときは、中断されたことを、他の失敗と区別できる形で返さなければならない (MUST)。

合成には、停止を求めるかどうかを答える関数を渡せなければならない (MUST)。バインディングは、speech.cpp の進捗コールバックと音声コールバックのたびにこの関数を呼び、停止を求められたら speech.cpp に停止を返さなければならない (MUST)。こうして止まった合成は中断の結果とし、音声コールバックの中で起きた失敗とは区別しなければならない (MUST)。中断のために、合成中のリクエストのポインタを他の isolate やスレッドに渡してはならない (MUST NOT)。

#### Scenario: 合成の成功
- **WHEN** 読み込んだモデルで1文を合成する
- **THEN** 空ではない音声と、モデルが報告するサンプルレートが返る

#### Scenario: 中断された合成
- **WHEN** 合成中に、停止を求める関数が停止を求めるようになる
- **THEN** 合成は中断されたことを示す結果で終わり、他の失敗とは区別される

#### Scenario: 進捗のたびに停止を確かめる
- **WHEN** 停止を求める関数を渡して合成する
- **THEN** speech.cpp が進捗を報告するたびに、その関数が呼ばれる

### Requirement: 参照音声を名前付きの voice として登録できる

バインディングは、読み込んだモデルに、WAVE ファイルまたは voice ファイルを、名前を付けた voice として登録できなければならない (MUST)。登録した voice は、合成のリクエストで `voice` オプションに名前を指定して使えなければならない (MUST)。speech.cpp が登録を拒否したときは、状態の名前と speech.cpp の詳細を含むエラーにしなければならない (MUST)。

#### Scenario: WAVE ファイルの登録
- **WHEN** 読み込んだモデルに WAVE ファイルを名前を付けて登録し、その名前を `voice` に指定して合成する
- **THEN** 登録も合成も成功する

#### Scenario: 読めないファイルの登録
- **WHEN** WAVE でも voice ファイルでもないファイルを登録する
- **THEN** 状態の名前と speech.cpp の詳細を含むエラーになる
