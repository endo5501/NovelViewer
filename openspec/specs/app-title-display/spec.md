## Purpose

AppBarのタイトルを現在のディレクトリ状態に応じて動的に切り替える。小説フォルダ（およびそのサブディレクトリ）配下では小説メタデータの `title` を表示し、メタデータがなければフォルダ名、ライブラリルートでは「NovelViewer」を表示する。

## Requirements

### Requirement: AppBarに選択中の小説タイトルを表示する

AppBarのタイトル領域は、**テキストビューアが表示しているエピソード**に基づいて動的にテキストを表示しなければならない（SHALL）。読書コンテキスト（`reading-context` 参照）が存在する場合、その小説のタイトルを表示しなければならない（SHALL）。ファイルブラウザの現在地を参照してはならない（SHALL NOT）。AppBar は本文の上にあり、読者に対して「いま何を読んでいるか」を答えるものだからである。

小説のタイトルは、読書中の小説フォルダのフォルダ名に一致するメタデータの `title` とする。メタデータが無いフォルダでは、そのフォルダ名を表示しなければならない（SHALL）。ただし読書中の小説フォルダがライブラリルート自身である場合 — ライブラリ直下に置かれたテキストファイルを開いている場合 — 名乗るべき作品が無いため「NovelViewer」を表示しなければならない（SHALL）。ライブラリフォルダは作品ではない。

#### Scenario: ライブラリルートにいるとき
- **WHEN** テキストビューアがファイルを表示しておらず、ファイルブラウザがライブラリルートにある
- **THEN** AppBarのタイトルは「NovelViewer」と表示される

#### Scenario: 小説フォルダを選択しているとき
- **WHEN** ユーザーが登録済み小説フォルダのエピソードを表示している
- **THEN** AppBarのタイトルはその小説のメタデータに登録されたタイトルを表示する

#### Scenario: 小説フォルダのサブディレクトリにいるとき
- **WHEN** ユーザーが整理用サブフォルダ内の小説フォルダのエピソードを表示している
- **THEN** AppBarのタイトルはその小説のメタデータに登録されたタイトルを表示する

#### Scenario: メタデータが未登録の小説フォルダにいるとき
- **WHEN** ユーザーがメタデータの存在しないフォルダのテキストファイルを表示している
- **THEN** AppBarのタイトルはそのフォルダ名を表示する

#### Scenario: 表示中のエピソードが無いとき
- **WHEN** テキストビューアがファイルを表示していない
- **THEN** AppBarのタイトルは「NovelViewer」と表示される（ファイルブラウザがどこにあっても同じ）

#### Scenario: ライブラリルート直下のファイルを開いているとき
- **WHEN** ユーザーがライブラリルート直下に置かれたテキストファイルを表示している
- **THEN** AppBarのタイトルの作品名部分は「NovelViewer」になる（ライブラリフォルダ名にはならない）

#### Scenario: ファイルブラウザを動かしてもタイトルは変わらない
- **WHEN** あるエピソードを表示したまま、ファイルブラウザをライブラリルートや別の小説フォルダへ移動する
- **THEN** AppBarのタイトルは表示中のエピソードの小説を示し続ける

### Requirement: AppBar に現在ファイル名と話数進捗を表示する

テキストビューアがエピソードを表示している場合、AppBar のタイトル領域は「小説タイトル — `ファイル名` (`現在話数`/`総話数`)」形式で表示しなければならない（SHALL）。

- `小説タイトル` は既存の「Requirement: AppBarに選択中の小説タイトルを表示する」と同じ導出による。
- `ファイル名` は表示中のファイル名をそのまま使う（拡張子を含む）。
- `現在話数` は、**読書コンテキストの話一覧**（`reading-context` 参照）における表示中ファイルの 1-based インデックス。
- `総話数` は、その話一覧のファイル数。
- セパレータは em-dash `—`（U+2014）、進捗は半角括弧 ` (N/M)` を使う。

分母・分子はいずれもファイルブラウザの現在地の一覧から取ってはならない（SHALL NOT）。ブラウザは読者が次に読むものを探して別の場所へ動くため、そこから取ると進捗が消えたり、無関係なフォルダの件数を示したりする。

話一覧が空、または表示中のファイルが無い場合、AppBar タイトルは小説タイトルのみ、あるいは「NovelViewer」を表示しなければならない（SHALL）。

タイトル全体は単一行で表示し、長さがウィンドウ幅を超える場合は省略記号（`TextOverflow.ellipsis`）で末尾を切り詰めなければならない（SHALL）。

#### Scenario: 小説フォルダ内でファイルを選択しているとき
- **WHEN** ユーザーが小説タイトル「異世界転生」の 49 番目のエピソード `049-戦闘.txt`（その小説の総話数 200）を表示している
- **THEN** AppBar のタイトルは「異世界転生 — 049-戦闘.txt (49/200)」と表示される

#### Scenario: ファイルブラウザを動かしても進捗は変わらない
- **WHEN** 上記の状態からファイルブラウザをライブラリルートへ移動する
- **THEN** AppBar のタイトルは「異世界転生 — 049-戦闘.txt (49/200)」のままである

#### Scenario: 小説フォルダ内でファイル未選択のとき
- **WHEN** テキストビューアがファイルを表示しておらず、ファイルブラウザが小説「異世界転生」のフォルダにある
- **THEN** AppBar のタイトルは「NovelViewer」と表示される。読書コンテキストは表示中のエピソードから導かれ、ブラウザの現在地からは導かれないため

#### Scenario: メタデータ未登録フォルダ内でファイルを選択しているとき
- **WHEN** ユーザーがメタデータ未登録のフォルダ「unknown_novel」の `001-序章.txt`（そのフォルダの総数 3）を表示している
- **THEN** AppBar のタイトルは「unknown_novel — 001-序章.txt (1/3)」と表示される

#### Scenario: ライブラリルートにいるとき
- **WHEN** テキストビューアがファイルを表示しておらず、ファイルブラウザがライブラリルートにある
- **THEN** AppBar のタイトルは「NovelViewer」と表示される（ファイル名や進捗は付与されない）

#### Scenario: タイトルがウィンドウ幅を超えるとき
- **WHEN** 小説タイトル＋ファイル名＋進捗の合計文字数が AppBar の表示幅を超える
- **THEN** タイトルは単一行で表示され、末尾が省略記号で切り詰められる

### Requirement: ファイル進捗付きタイトルを Provider で提供する

システムは、読書コンテキスト（`reading-context` 参照）と表示中のファイルから、上記の「小説タイトル — ファイル名 (N/M)」形式の文字列を導出する派生 Provider を提供しなければならない（SHALL）。AppBar の Widget はこの派生 Provider のみを参照し、組み立てロジックを Widget 内に持ってはならない（SHALL NOT）。

この派生 Provider は `currentDirectoryProvider` および `directoryContentsProvider` に依存してはならない（SHALL NOT）。

#### Scenario: 派生 Provider が組み立てを担う
- **WHEN** AppBar の Widget がタイトル表示用 Provider を watch する
- **THEN** Widget はその文字列値をそのまま `Text` ウィジェットに渡すだけでよく、ファイル名や進捗の合成を Widget 内で行わない

#### Scenario: 依存 Provider の変化で派生 Provider が再計算される
- **WHEN** 表示中のファイルが変わる
- **THEN** 派生 Provider は新しいファイル名と進捗インデックスを反映した文字列を返す

#### Scenario: ブラウザの現在地では再計算されない
- **WHEN** 表示中のファイルを変えずにファイルブラウザの現在地だけが変わる
- **THEN** 派生 Provider の返す文字列は変わらない
