# Spec Delta

## ADDED Requirements

### Requirement: TTSエピソードのファイル名を付け替える

システムは、TTS エピソードが記録しているファイル名を、旧名から新名へ付け替える操作を提供しなければならない（SHALL）。付け替えでは、そのエピソードの生成状態とすべてのセグメント（音声データ、テキスト、編集内容）を保持しなければならない（SHALL）。

付け替え先の新名に TTS エピソードが既にある場合は、新名のエピソードを残し、旧名のエピソードをそのセグメントごと削除しなければならない（SHALL）。

#### Scenario: 生成済み音声が新しい名前で引ける

- **WHEN** `3_x.txt` に生成済みの TTS エピソードとセグメントがあり、`3_x.txt` → `03_x.txt` の付け替えが行われる
- **THEN** `03_x.txt` で TTS エピソードを引くと、同じ生成状態とセグメントが得られる

#### Scenario: 新名側にもエピソードがある

- **WHEN** `3_x.txt` と `03_x.txt` の両方に TTS エピソードがあり、`3_x.txt` → `03_x.txt` の付け替えが行われる
- **THEN** `03_x.txt` のエピソードが残り、`3_x.txt` のエピソードとそのセグメントは削除される
