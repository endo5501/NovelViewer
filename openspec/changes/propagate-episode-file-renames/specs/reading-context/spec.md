# Spec Delta

## ADDED Requirements

### Requirement: 読書コンテキストは更新によるファイル名の変更で失われない

小説のダウンロードまたは更新によって、表示中のエピソードのファイルがリネームされた場合、システムはその選択を新しいファイルのパスへ付け替えなければならない（SHALL）。付け替えないと、選択は存在しないファイルを指し続ける。その結果、話一覧の中で表示中のエピソードの位置が見つからず、前後の話へ遷移できなくなる。

この付け替えは、ファイルを開く操作として扱ってはならない（SHALL NOT）。フォルダの移動・改名に追従する場合と同じ理由による。

表示中のエピソードがリネームの対象でない場合、または別の小説やフォルダのものである場合は、選択を変更してはならない（SHALL NOT）。

#### Scenario: 桁上がりの更新後も次話へ遷移できる

- **WHEN** 9話構成の小説で `9_x.txt` を表示したまま更新し、12話になって `9_x.txt` が `09_x.txt` へリネームされる
- **THEN** 表示中のエピソードは `09_x.txt` を指し、次話 `10_….txt` へ遷移できる

#### Scenario: 付け替えはファイルブラウザを閉じない

- **WHEN** ファイルブラウザを開いた状態で、表示中のエピソードが更新によりリネームされる
- **THEN** 選択は付け替えられるが、ファイルを開く操作としては扱われず、ファイルブラウザは開いたままである

#### Scenario: 別の小説を表示中なら選択は変わらない

- **WHEN** ある小説を表示したまま、ファイルブラウザから別の小説を更新し、その別の小説のファイルがリネームされる
- **THEN** 表示中のエピソードの選択は変わらない
