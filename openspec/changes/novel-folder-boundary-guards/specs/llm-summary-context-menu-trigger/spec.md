## ADDED Requirements

### Requirement: 解析は登録済み小説フォルダでのみ開始できる

システムは、LLM 解析の対象フォルダを、ファイルブラウザの現在地から解決した**登録済み小説フォルダ**としなければならない（SHALL）。解決は入れ子の深さに依存しない共有ルールに従い、現在地またはその祖先のうち最も近い登録済み小説フォルダを対象とする。

登録済み小説フォルダを解決できない場合 — ライブラリルート、および登録済み小説フォルダを祖先に持たない整理フォルダ — システムは解析を開始してはならず（SHALL NOT）、その場所の `novel_data.db` を開いてはならない（SHALL NOT）。開けばファイルが作られるため、小説でない場所に小説用のデータベースが残る。ユーザーには既存の「小説フォルダを開いてください」を提示しなければならない（SHALL）。これはブックマークが同じ場所で無効であるのと同一の境界である。

解析に用いる**話数の算出**（対象上限話数、および全話スコープの参照先ファイル）は、対象フォルダではなく、**表示中のファイルが置かれているフォルダ**の `.txt` 一覧から導かなければならない（SHALL）。スナップショットに記録される `source_file` はその一覧に属する名前であり、データベースの所在とは別の事柄である。

#### Scenario: 小説フォルダで解析を開始する

- **WHEN** ユーザーが登録済み小説フォルダのエピソードを表示した状態で「解析開始(ネタバレなし)」を選ぶ
- **THEN** 解析はその小説フォルダの `novel_data.db` を対象に開始される

#### Scenario: 入れ子の小説フォルダでも開始できる

- **WHEN** 整理フォルダの配下に置かれた登録済み小説フォルダのエピソードを表示した状態で解析を開始する
- **THEN** 解析はその小説フォルダを対象に開始される

#### Scenario: 整理フォルダでは解析が開始されない

- **WHEN** 登録済み小説フォルダを祖先に持たない整理フォルダのテキストを表示した状態で解析を開始しようとする
- **THEN** 解析は開始されず、「小説フォルダを開いてください」が提示される
- **AND** そのフォルダに `novel_data.db` は作られない

#### Scenario: ライブラリルートでは解析が開始されない

- **WHEN** ライブラリルート直下のテキストを表示した状態で解析を開始しようとする
- **THEN** 解析は開始されず、「小説フォルダを開いてください」が提示される
- **AND** ライブラリルートに `novel_data.db` は作られない

#### Scenario: 話数は表示中のファイルのフォルダから導かれる

- **WHEN** 小説フォルダのエピソードを表示した状態で「解析開始(ネタバレあり)」を選ぶ
- **THEN** 上限話数と参照先ファイルは、表示中のファイルが置かれているフォルダの `.txt` 一覧から導かれる
