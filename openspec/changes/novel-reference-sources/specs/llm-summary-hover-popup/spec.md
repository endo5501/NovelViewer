# Spec Delta

## ADDED Requirements

### Requirement: 要約カードに参照元の一覧を表示する

表示中のスナップショットに参照元の一覧（`llm-summary-cache` の「スナップショットは解析に使った参照元を記録する」）が記録されている場合、要約カードは、その一覧を「参照元: 『A』、『B』」の形で表示しなければならない（SHALL）。タイトルは、スナップショットに記録された解析時点のタイトルを使わなければならない（SHALL）。表示位置は「Xファイル時点の要約」ラベルの近くとし、要約本文と区別できる控えめな体裁にする。

一覧が空のスナップショットでは、この表示を出してはならない（SHALL NOT）。スナップショットの切り替え（◀ / ▶）に合わせて、表示中のスナップショットの一覧に更新しなければならない（SHALL）。

詳細ダイアログの「解析結果」タブは同じ要約カードを流用するため、同じ表示になる。「参照元:」の文言は en / ja / zh の `.arb` にすべて存在しなければならない（SHALL）。

#### Scenario: 参照元つきスナップショットに一覧が出る
- **WHEN** 『第1部』と『Wikipedia 記事集』を参照元として解析したスナップショットをポップアップで表示する
- **THEN** カードに「参照元: 『第1部』、『Wikipedia 記事集』」が表示される

#### Scenario: 参照元なしのスナップショットには出ない
- **WHEN** 参照元の一覧が空のスナップショットを表示する
- **THEN** 参照元の表示は出ない

#### Scenario: スナップショットを切り替えると一覧も切り替わる
- **WHEN** 参照元つきのスナップショットから、参照元なしのスナップショットへ ▶ で切り替える
- **THEN** 参照元の表示は消える

#### Scenario: 詳細ダイアログでも表示される
- **WHEN** 参照元つきのスナップショットを持つ語の詳細ダイアログで「解析結果」タブを開く
- **THEN** 要約カードに参照元の一覧が表示される
