# Spec Delta

## ADDED Requirements

### Requirement: 小説の削除は参照元関係も削除する

確認ダイアログで「削除」を選択した際、システムは、`novels` と `reading_progress` の削除と同じ `novel_metadata.db` のトランザクションの中で、削除対象の小説（`folder_name`）が子・親どちらの側にある参照元関係もすべて削除しなければならない（SHALL）。この削除も、ファイルシステムの削除が成功した後にだけ行う。トランザクションが失敗した場合は、関係の行も削除されずに残らなければならない（SHALL）。

#### Scenario: 削除で関係が消える
- **WHEN** 『第1部』を参照元とする『第2部』があり、『第1部』自身も『設定資料集』を参照元に持つ状態で、『第1部』を削除する
- **THEN** 『第2部』→『第1部』と『第1部』→『設定資料集』の関係は、どちらも削除される

#### Scenario: トランザクションの失敗で関係も残る
- **WHEN** `novel_metadata.db` の削除トランザクションが途中で失敗する
- **THEN** `novels`・`reading_progress`・参照元関係のいずれの行も削除されない

#### Scenario: フォルダ削除の失敗で関係は残る
- **WHEN** ファイルシステムの小説フォルダの削除が失敗する
- **THEN** 参照元関係は削除されない
