## MODIFIED Requirements

### Requirement: ペイン間フォーカス切替（Tab限定）

`switchPane` アクション（既定Tab）は、ファイルブラウザ（左カラム）と小説画面（中央カラム）の2ペイン間**のみ**でフォーカスを切り替えなければならない（SHALL）。AppBarのボタン群（しおり・右カラム切替・検索・ダウンロード・設定）はTabによるフォーカス巡回の対象に含めてはならない（SHALL NOT）。検索入力フィールドにフォーカスがある間は、Tabをペイン切替に使用してはならない（SHALL NOT）。

narrowレイアウトでは左ペインが`Drawer`の中にあり、閉じている間はマウントされていない。この状態で `switchPane` のバインディングを登録してはならない（SHALL NOT）——登録すればキー入力を消費して何も起こさないバインディングとなり、しかも利用者はその存在を見ることも変更することもできない。未登録であればTabは通常のフォーカス送りとして扱われる。同じ理由により、narrowレイアウトでは起動時のファイルブラウザへのフォーカス要求も行ってはならない（SHALL NOT）。

#### Scenario: Tabで2ペイン間を往復する
- **WHEN** wideレイアウトでファイルブラウザにフォーカスがある状態で `switchPane`（Tab）を押す
- **THEN** フォーカスが小説画面に移り、再度押すとファイルブラウザに戻る

#### Scenario: AppBarボタンへフォーカスが移らない
- **WHEN** いずれかのペインにフォーカスがある状態で `switchPane`（Tab）を繰り返し押す
- **THEN** フォーカスはAppBarのしおり・右カラム切替・検索・ダウンロード・設定ボタンには移らない

#### Scenario: 検索入力中はペイン切替が抑制される
- **WHEN** 検索入力フィールドにフォーカスがある状態でTabを押す
- **THEN** ペイン切替は発生しない

#### Scenario: narrowレイアウトではバインディングを登録しない
- **WHEN** narrowレイアウトでショートカットマップが構築される
- **THEN** `switchPane` のエントリは含まれず、そのキー組み合わせは他のハンドラに委ねられる

#### Scenario: narrowレイアウトでは起動時にどのペインもフォーカスを持たない
- **WHEN** narrowレイアウトでアプリが起動する
- **THEN** ファイルブラウザペインはフォーカスを持たない（Drawerの中にあり、そのスコープがツリーに存在しないため）
