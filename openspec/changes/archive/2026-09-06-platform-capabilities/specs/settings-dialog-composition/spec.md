## MODIFIED Requirements

### Requirement: AboutAndUpdateSection の表示項目
`AboutAndUpdateSection` は以下の情報を、プラットフォームを問わず常に含まなければならない（SHALL）。

- 現在のアプリバージョン（`PackageInfo.fromPlatform()` から取得）
- ビルド番号

以下の情報・操作は、自己更新に対応するプラットフォームでのみ含めなければならない（SHALL）。対応しないプラットフォームでは表示してはならない（MUST NOT）。行われないチェックの状態を示すことになり、また配布形態（インストーラ版 / ポータブル版）は Windows のインストーラ配布と ZIP 配布を区別するための概念であって、それ以外のプラットフォームでは事実を表さないためである。

- 配布形態の表示（「インストーラ版」または「ポータブル版 (ZIP)」、ローカライズ済み）
- 最終更新確認日時（未確認の場合は「未確認」）
- 「更新を確認」ボタン（手動チェック起動、押下中はインジケータ表示）
- 「自動チェック」ON/OFF スイッチ（デフォルト ON）

当該セクションは、自己更新の可否を機能別の capability provider から取得しなければならない（SHALL）。`dart:io` の `Platform` を直接読んではならない（MUST NOT）。

#### Scenario: バージョン情報の表示
- **WHEN** `AboutAndUpdateSection` がレンダリングされる
- **THEN** 現在バージョン・ビルド番号が画面上で確認できる

#### Scenario: 対応プラットフォームでは更新項目が揃う
- **WHEN** 自己更新に対応するプラットフォームで `AboutAndUpdateSection` がレンダリングされる
- **THEN** 配布形態・最終更新確認日時・「更新を確認」ボタン・「自動チェック」スイッチが表示される

#### Scenario: 未対応プラットフォームでは更新項目が消える
- **WHEN** 自己更新を持たないプラットフォームで `AboutAndUpdateSection` がレンダリングされる
- **THEN** 配布形態・最終更新確認日時・「更新を確認」ボタン・「自動チェック」スイッチはいずれも表示されず、バージョンとビルド番号のみが残る

#### Scenario: 「更新を確認」ボタンの動作
- **WHEN** 自己更新に対応するプラットフォームでユーザが「更新を確認」ボタンを押す
- **THEN** 押下中はローディングインジケータが表示され、結果（「最新です」または「v* が利用可能」）が同セクション内に表示される

#### Scenario: 自動チェックスイッチの永続化
- **WHEN** ユーザが自動チェックスイッチを切り替える
- **THEN** `SharedPreferences` の `app_update.auto_check_enabled` キーが対応する値で更新される
