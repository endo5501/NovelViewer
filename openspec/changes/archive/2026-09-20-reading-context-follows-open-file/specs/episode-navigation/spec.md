## MODIFIED Requirements

### Requirement: 隣接ファイル導出 Provider

システムは、**読書コンテキストの話一覧**（`reading-context` 参照）と表示中のファイルから、「次のファイル」「前のファイル」を導出する Riverpod provider を提供しなければならない（SHALL）。並びは `file-browser` capability の数値プレフィックスソート（`sortByNumericPrefix`）と一致しなければならない（SHALL）。導出結果はテキスト拡張子（`.txt`）のファイルのみを対象とし、サブディレクトリは含まない。

導出はファイルブラウザの現在地の一覧（`directoryContentsProvider`）に依存してはならない（SHALL NOT）。ファイルブラウザは `Drawer` の中で本文とは独立に移動するため、そこに依存すると、読者が次に読むものを探しただけで話送りが止まる。この provider は次話・前話の唯一の供給源であり、縦書き・横書き双方のページ送りによる話送りがこれを読む。

#### Scenario: 中間ファイルが選択されているとき
- **WHEN** 読書中の小説フォルダに 5 つのテキストファイル（数値プレフィックスでソート済み）があり、3 番目を表示している
- **THEN** Provider は「次のファイル」として 4 番目の `FileEntry` を返し、「前のファイル」として 2 番目の `FileEntry` を返す

#### Scenario: 先頭ファイルが選択されているとき
- **WHEN** 読書中の小説フォルダに 5 つのテキストファイルがあり、1 番目を表示している
- **THEN** Provider は「次のファイル」として 2 番目の `FileEntry` を返し、「前のファイル」として `null` を返す

#### Scenario: 末尾ファイルが選択されているとき
- **WHEN** 読書中の小説フォルダに 5 つのテキストファイルがあり、5 番目を表示している
- **THEN** Provider は「次のファイル」として `null` を返し、「前のファイル」として 4 番目の `FileEntry` を返す

#### Scenario: 唯一のファイルが選択されているとき
- **WHEN** 読書中の小説フォルダにテキストファイルが 1 つしかなく、それを表示している
- **THEN** Provider は「次のファイル」「前のファイル」ともに `null` を返す

#### Scenario: ファイルが選択されていないとき
- **WHEN** テキストビューアがファイルを表示していない
- **THEN** Provider は「次のファイル」「前のファイル」ともに `null` を返す

#### Scenario: 選択ファイルがディレクトリ内に見つからないとき
- **WHEN** 表示中のファイルが読書コンテキストの話一覧に含まれていない（例: 一覧の取得が完了する前の過渡状態、または表示中にファイルが削除された）
- **THEN** Provider は「次のファイル」「前のファイル」ともに `null` を返す

#### Scenario: ファイルブラウザを動かしても話送りは効き続ける
- **WHEN** あるエピソードを表示したまま、ファイルブラウザをライブラリルートや別の小説フォルダへ移動する
- **THEN** Provider は表示中のエピソードの隣を返し続け、ページ送りによる話送りは変わらず機能する
