## 7a. レビュー由来の修正

- [x] 7a.1 Apple Pencil（stylus）が縦書きのタップ判定から漏れていた。判定を「副ボタンを持たないポインタ」（touch / stylus / invertedStylus）に改め、共有定数 `kNoSecondaryButtonPointerKinds` に切り出した
- [x] 7a.2 列間ギャップのタップが選択を破棄していた。`hitTestCharIndexFromRegions` に `maxSnapDistance` を追加し、`columnSpacing` を上限に吸着させた。無制限吸着では余白のタップが壊れることもテストで固定
- [x] 7a.3 「Drawer が閉じない」テストがパネルの存在しか見ておらず、長押しを外しても通っていた。メニューの表示も併せて検証するよう強化
- [x] 7a.4 リスト項目の長押しを副ボタンを持たないポインタに限定。探索時の「マウスでも何も失われない」という前提が誤りで、実際には遅い左クリックがタイルを開けなくなっていた（実測確認済み）
- [x] 7a.5 解析履歴パネルにも長押しを追加。iPad では非表示だがタッチスクリーン付きデスクトップでは到達手段が無く、新設仕様の文言と矛盾していた
- [x] 7a.6 Finding 8（改行フォールバックの不一致）は誤りと判定。`realLineBreakEntries` は null 時の挙動を集合として具体化したもので両者は一致する。回帰テストのみ追加
