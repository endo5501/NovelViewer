## MODIFIED Requirements

### Requirement: 単語詳細ダイアログの起動

解析履歴エントリの右クリックメニューで「詳細を表示」が選択されたとき、および要約ポップアップの「詳細を表示」ボタンが押されたとき、システムはその単語に対する read-only の詳細ダイアログを表示しなければならない（SHALL）。ダイアログは「事実」タブと「解析結果」タブの2タブ構成とし、起動直後は「事実」タブを選択状態とする。ダイアログのタイトルには対象の単語を表示する。どちらの起動元から開いても、ダイアログの内容と振る舞いは同一でなければならない（SHALL）。

ダイアログが読み込む対象は、起動元が表示していた小説フォルダのデータベースでなければならない（SHALL）。解析履歴メニューからなら一覧を読み込んだ小説、要約ポップアップからならポップアップを開いた小説である。

#### Scenario: 詳細ダイアログを開く

- **WHEN** ユーザーが履歴エントリ「アリス」の右クリックメニューで「詳細を表示」を選択する
- **THEN** タイトルに「アリス」を含む詳細ダイアログが表示される
- **AND** 「事実」タブと「解析結果」タブが表示され、「事実」タブが選択状態である

#### Scenario: 要約ポップアップから詳細ダイアログを開く

- **WHEN** ユーザーが単語「アリス」の要約ポップアップで「詳細を表示」ボタンを押す
- **THEN** タイトルに「アリス」を含む詳細ダイアログが表示される
- **AND** 「事実」タブと「解析結果」タブが表示され、「事実」タブが選択状態である
- **AND** 表示される事実と解析結果は、ポップアップを開いた小説フォルダのものである

#### Scenario: ダイアログを閉じる

- **WHEN** ユーザーが詳細ダイアログの閉じる操作（閉じるボタン、ダイアログ外タップ、または Esc）を行う
- **THEN** ダイアログが閉じ、解析履歴パネルの状態は変化しない
