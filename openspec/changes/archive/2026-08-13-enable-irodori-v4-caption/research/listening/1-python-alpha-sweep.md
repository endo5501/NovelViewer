# 試聴チェックシート

音響プロキシ（区間数）では判定できなかったケースを人間の耳で決着させるためのセット。
`../validation-plan-and-results.md` の判定基準 2/3 に対応する。

**聴き方:** 各グループは対照とセットになっている。番号順に聴いて、
**「入力テキストに無い発話が末尾に付いているか」** だけを見る。
間の長さや速度の自然さは別項目（下の「品質」欄）。

入力テキスト:

- **T1 / C2 / C3 グループ**: 「どうしてもっと早く教えてくれなかったの？私、ずっと待ってたのに。」
- **T3 グループ**: 「窓の外では、粉雪が音もなく降り積もっていた。彼女はカーテンの隙間からその白い景色を、ただ黙って見つめている。」

caption:

- **C1**（T1 グループ）: 深く傷つき、今にも泣き出しそうな様子。声が震えており、悲痛なトーンで弱々しく話す。
- **C2**: ゆっくりと間を取りながら、落ち着いた低い声で穏やかに語りかける。
- **C3**: 明るく元気いっぱいに、弾むような早口で楽しそうに話す。

## D. T3（中文）はそもそも発生しているか

T3 は基準の noref 側にも 2/10 のフラグが出ており、プロキシが機能していない疑いが濃い。
D2 は 8 区間と最も多く検出された例。

| # | ファイル | 尺 | プロキシ判定 | 余計な発話は? | 品質 |
|---|---|---:|---|---|---|
| D1 | `D1_T3_noref_seed1238_CONTROL.wav` | 11.20 | クリーン | ☐あり ☐なし | |
| D2 | `D2_T3_nocorr_seed1238.wav` | 11.64 | 発生 | ☐あり ☐なし | |

**D2 が「あり」なら T3 でも現象は起きており、noref 予測ベースの補正では
効かない**（T3 は noref 予測 11.20 と実予測 11.64 がほぼ同じため補正が no-op になる）
**ことになり、方針の見直しが必要。**
**D2 が「なし」なら T3 は無関係で、現象は短めのテキストに限られる。**
