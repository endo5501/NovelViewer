# Spec Delta

## ADDED Requirements

### Requirement: 要約のジャンプ先ファイル名を付け替える

システムは、要約スナップショットが記録しているジャンプ先のファイル名（`source_file`）を、旧名から新名へ付け替える操作を提供しなければならない（SHALL）。要約の本文、対象範囲（`covered_up_to_episode`）、更新日時は変更してはならない（SHALL NOT）。

対象範囲はファイル名の先頭の数値で表されている。ゼロ埋め幅が変わっても数値は変わらないので、対象範囲を付け替える必要はない。

#### Scenario: 履歴から新しい名前のファイルへジャンプできる

- **WHEN** 語「アリス」の要約スナップショットのジャンプ先が `9_x.txt` であり、`9_x.txt` → `09_x.txt` の付け替えが行われる
- **THEN** そのスナップショットのジャンプ先は `09_x.txt` になり、対象範囲は9のまま変わらない
