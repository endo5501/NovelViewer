# Spec Delta

## ADDED Requirements

### Requirement: 読書進捗のファイル名を付け替える

システムは、ある小説の読書進捗が記録しているファイル名を、旧名から新名へ付け替える操作を提供しなければならない（SHALL）。付け替えでは、本文内の位置（オフセットと本文ハッシュ）を保持しなければならない（SHALL）。また、最終更新時刻を変更してはならない（SHALL NOT）。起動時の復元は最終更新時刻が最も新しい進捗を選ぶため、付け替えだけで「最後に読んだ小説」が入れ替わってはならないからである。

読書進捗が付け替え対象の旧名を指していない場合、操作は何も変更してはならない（SHALL NOT）。

#### Scenario: ファイル名だけが変わり位置は保たれる

- **WHEN** ある小説の読書進捗が `9_x.txt` の本文オフセット1200を記録しており、`9_x.txt` → `09_x.txt` の付け替えが行われる
- **THEN** 読書進捗は `09_x.txt` のオフセット1200を指し、本文ハッシュと最終更新時刻は変わらない

#### Scenario: 別のファイルを指す進捗は変わらない

- **WHEN** 読書進捗が `5_x.txt` を指しており、`9_x.txt` → `09_x.txt` の付け替えが行われる
- **THEN** 読書進捗は変更されない

#### Scenario: 付け替え後の再オープンで復元される

- **WHEN** 付け替えの後、利用者がその小説のフォルダに入る
- **THEN** `09_x.txt` が自動的に開かれる
