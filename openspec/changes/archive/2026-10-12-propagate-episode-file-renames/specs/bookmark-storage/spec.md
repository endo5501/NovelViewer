# Spec Delta

## ADDED Requirements

### Requirement: ブックマークのファイル名を付け替える

システムは、小説のブックマークが記録しているファイル名を、旧名から新名へ付け替える操作を提供しなければならない（SHALL）。行番号と作成日時は保持しなければならない（SHALL）。

付け替え先の新名に、同じ行番号のブックマークが既にある場合は、新名のブックマークを残し、旧名のブックマークを破棄しなければならない（SHALL）。この規則は、ファイル単位のブックマーク（行番号なし）にも適用しなければならない（SHALL）。

#### Scenario: ブックマークが新しい名前へ移る

- **WHEN** `3_x.txt` の10行目と、行番号なしのブックマークがあり、`3_x.txt` → `03_x.txt` の付け替えが行われる
- **THEN** `03_x.txt` に10行目と行番号なしのブックマークがあり、`3_x.txt` のブックマークは無くなる

#### Scenario: 同じ行のブックマークが新名側にもある

- **WHEN** `3_x.txt` と `03_x.txt` の両方に10行目のブックマークがあり、`3_x.txt` → `03_x.txt` の付け替えが行われる
- **THEN** `03_x.txt` の10行目のブックマークは1件だけ残る

#### Scenario: ファイル単位のブックマークが重複しない

- **WHEN** `3_x.txt` と `03_x.txt` の両方に行番号なしのブックマークがあり、`3_x.txt` → `03_x.txt` の付け替えが行われる
- **THEN** `03_x.txt` の行番号なしのブックマークは1件だけ残る
