# Spec Delta

## ADDED Requirements

### Requirement: 事実キャッシュのファイル名を付け替える

システムは、事実キャッシュの行が記録しているファイル名を、旧名から新名へ付け替える操作を提供しなければならない（SHALL）。抽出済みの事実、本文ハッシュ、プロンプトバージョン、モデル識別子は保持しなければならない（SHALL）。本文は変わっていないので、付け替え後の行は有効なキャッシュとして再利用されなければならない（SHALL）。

付け替え先に、同じ語とモデルの新名の行が既にある場合は、新名の行を残し、旧名の行を破棄しなければならない（SHALL）。

#### Scenario: 付け替え後もキャッシュが再利用される

- **WHEN** `3_x.txt` について語「アリス」の事実がキャッシュされており、`3_x.txt` → `03_x.txt` の付け替えが行われる
- **THEN** `03_x.txt` について同じ語・同じモデルで要約を行うと、キャッシュされた事実が再利用され、再抽出は行われない

#### Scenario: 新名側にも同じ語とモデルの行がある

- **WHEN** 語「アリス」、同じモデルの行が `3_x.txt` と `03_x.txt` の両方にあり、`3_x.txt` → `03_x.txt` の付け替えが行われる
- **THEN** `03_x.txt` の行が1件だけ残る
