# Spec Delta

## ADDED Requirements

### Requirement: 参照元の祖先を解析範囲に含める

解析対象の小説が参照元を持つ場合、システムは、その小説の祖先（`novel-reference-sources` の「祖先の解決」）のテキストファイルを、表示中の小説の証拠に加えて解析しなければならない（SHALL）。子の方向の小説は加えてはならない（SHALL NOT）。

各祖先から読む範囲は、解析の種類によって次のとおり決まる（SHALL）。

| 解析の種類 | 表示中の小説 | 各祖先 |
|---|---|---|
| 簡易 | 語の初出ファイル（従来どおり） | その祖先で語を含む話数が最小のファイル。語を含まない祖先からは何も読まない |
| ネタバレなし | 1..C（従来どおり） | その祖先のすべてのテキストファイル |
| ネタバレあり | すべて（従来どおり） | その祖先のすべてのテキストファイル |

祖先のファイルで語を含むかどうかは、表示中の小説と同じ一致判定で決めなければならない（SHALL）。

スナップショットの `covered_up_to_episode` と `source_file` は、従来どおり表示中の小説のファイルだけから決めなければならない（SHALL）。祖先のファイルが、これらの値に影響してはならない（SHALL NOT）。

参照元を持たない小説の解析は、読むファイル・LLM呼び出し・保存結果のいずれも、この変更の前と同じでなければならない（SHALL）。

#### Scenario: ネタバレなしは祖先の全体を読む
- **WHEN** 『第2部』の参照元が『第1部』（全50話）で、『第2部』の010話を表示中に「アリス」をネタバレなしで解析する
- **THEN** 証拠は、『第2部』の1..10話のうち語を含むファイルと、『第1部』の1..50話のうち語を含むファイルから集められる
- **AND** スナップショットは `covered_up_to_episode=10` で保存される

#### Scenario: 簡易は祖先ごとに初出ファイルを読む
- **WHEN** 『第2部』の参照元が『第1部』と『設定資料集』で、「アリス」が『第1部』の003話と020話に出てきて、『設定資料集』には出てこない状態で、簡易解析を行う
- **THEN** 『第1部』からは003話だけを読み、『設定資料集』からは何も読まない

#### Scenario: 子の作品は読まない
- **WHEN** 『外伝』の参照元が『第1部』で、『第1部』で解析を行う
- **THEN** 『外伝』のファイルは読まれない

#### Scenario: 参照元のない小説は従来どおり
- **WHEN** 参照元を持たない小説で解析を行う
- **THEN** 読むファイルと保存されるスナップショットは、従来と同じである

### Requirement: 再解析は祖先のファクトキャッシュも無効化する

再解析（既存のスナップショットと同じ `covered_up_to_episode` での解析）では、システムは、表示中の小説の `fact_cache` に加えて、各祖先の `fact_cache` にあるその語の行も無効化しなければならない（SHALL）。

無効化の範囲は、表示中の小説での無効化と同じ規則に従わなければならない（SHALL）。対象は、実行で使うモデルの行のうち、表示中の小説におけるその語の最新スナップショットの `updated_at` より新しくない行に限る。

#### Scenario: 再解析で祖先の行も再抽出される
- **WHEN** 『第2部』（参照元『第1部』）で、既存スナップショットと同じ上限で「アリス」を再解析する
- **THEN** 『第1部』の `fact_cache` にある「アリス」の行（同じモデル、上限時刻以前のもの）も無効化され、再抽出される

### Requirement: 進捗表示は祖先のファイルを含む

解析モーダルの「情報を抽出中」の `current / total` は、表示中の小説と祖先を合わせた、抽出が必要なファイル（キャッシュミス）の数で数えなければならない（SHALL）。祖先の事実を圧縮するための LLM 呼び出しは、既存の「絞り込み N 周目」の表示で示さなければならない（SHALL）。

1回の解析の中で、「絞り込み N 周目」の N は単調に増えなければならない（SHALL）。祖先ごとの圧縮と合流後の集約は、1つの周回番号を通して数える。画面上で番号が戻ってはならない（SHALL NOT）。

#### Scenario: 祖先のキャッシュミスが合計に含まれる
- **WHEN** 表示中の小説でキャッシュミスが2ファイル、祖先でキャッシュミスが3ファイルある
- **THEN** 抽出中の表示の合計は 5 になる

#### Scenario: 周回番号は戻らない
- **WHEN** 祖先『第1部』の圧縮が2周目・3周目で行われた後、合流後の集約が1周行われる
- **THEN** 合流後の集約は「絞り込み 4 周目」と表示される
