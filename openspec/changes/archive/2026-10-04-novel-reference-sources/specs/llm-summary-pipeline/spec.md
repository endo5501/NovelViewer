# Spec Delta

## ADDED Requirements

### Requirement: 祖先ごとに事実を圧縮する

解析に祖先が含まれる場合、システムは、各祖先の Stage-1 事実を祖先ごとにまとめなければならない（SHALL）。そのうえで、他の祖先や表示中の小説の事実と混ぜる前に、祖先ごとに圧縮しなければならない（SHALL）。

Stage-1 抽出は、祖先のファイルについても従来と同じくファイル単位で行う。異なる小説のファイルの文脈を、同じチャンクに詰めてはならない（SHALL NOT）。

1つの祖先の事実の合計が、クライアントが宣言する応答予算に収まる場合は、その事実をそのまま使わなければならない（SHALL）。収まらない場合は、その祖先の事実だけを入力とする集約ラウンドを、応答予算に収まるまで繰り返さなければならない（SHALL）。集約ラウンドの打ち切り規則（縮まなかった場合・深さの上限）と、出口で予算内に収める規則は、既存の集約と同じものを適用する。

事実が1つも得られなかった祖先は、合流に何も寄与してはならない（SHALL NOT）。

#### Scenario: 祖先の事実は他と混ぜずに圧縮される
- **WHEN** 祖先『第1部』の事実の合計が応答予算を超え、表示中の小説にも事実がある
- **THEN** 『第1部』の事実だけを入力とする集約ラウンドが行われる
- **AND** その集約ラウンドの入力に、表示中の小説の事実や他の祖先の事実は含まれない

#### Scenario: 小さい祖先の事実はそのまま使う
- **WHEN** 祖先『設定資料集』の事実の合計が応答予算に収まる
- **THEN** 『設定資料集』の事実を圧縮する LLM 呼び出しは行われない

### Requirement: 出典ラベル付きで事実を合流させる

システムは、各祖先の圧縮後の事実を、表示中の小説のファイル別の事実と合わせて、最終要約の入力となる事実の集合を作らなければならない（SHALL）。このとき、祖先の事実の先頭には、その祖先のタイトルを含む出典ラベル（例：「『第1部』より:」）を付けなければならない（SHALL）。表示中の小説の事実には、ラベルを付けてはならない（SHALL NOT）。

合流した事実の並びは、決定的な順序でなければならない（SHALL）。祖先の事実は、表示中の小説の事実より前に置く。

合流した事実が最終要約のプロンプトに収まらない場合は、既存の集約ラウンドで圧縮する。このとき集約プロンプトは、出典ラベルを保持し、異なる出典の事実を1つの事実に混ぜないよう指示しなければならない（SHALL）。

すべての出典を合わせても事実が1つも無い場合に限り、解析は既存の「事実なし」失敗で終わらなければならない（SHALL）。

#### Scenario: 祖先の事実にラベルが付く
- **WHEN** 祖先『第1部』と表示中の『第2部』の両方から「アリス」の事実が得られる
- **THEN** 最終要約の入力では、『第1部』の事実の先頭に「『第1部』より:」が付き、『第2部』の事実にはラベルが無い

#### Scenario: 合流後の集約はラベルを保持する
- **WHEN** 出典ラベル付きの事実を含む集合が最終要約の窓を超え、集約ラウンドが行われる
- **THEN** 集約プロンプトは、出典ラベルの保持と、異なる出典の事実を混ぜないことを指示する

#### Scenario: 祖先だけに事実がある場合も要約する
- **WHEN** 表示中の小説からは事実が得られず、祖先からは得られる
- **THEN** 解析は「事実なし」で失敗せず、最終要約が生成される

### Requirement: 出典ラベルがあるとき最終要約は本作を優先する

最終要約の入力に出典ラベル付きの事実が含まれる場合、最終要約のプロンプトは、次の3点を LLM に指示しなければならない（SHALL）。

- ラベルの無い事実は、表示中の作品（本作）のものである
- 本作の事実と参照元の事実が矛盾する場合は、本作の事実を優先する
- 同じ名前でも、参照元の記述が本作の対象と別のものを指していると判断できる場合は、混同しない

出典ラベル付きの事実が含まれない場合（参照元を持たない小説、または祖先から事実が得られなかった場合）、最終要約のプロンプトは従来と同じでなければならない（SHALL）。

#### Scenario: ラベルがあると優先指示が入る
- **WHEN** 最終要約の入力に「『第1部』より:」付きの事実が含まれる
- **THEN** 最終要約のプロンプトに、ラベルの無い事実が本作のものであること、矛盾時は本作を優先すること、同名の別物を混同しないことの指示が含まれる

#### Scenario: ラベルが無ければプロンプトは従来どおり
- **WHEN** 参照元を持たない小説で最終要約を生成する
- **THEN** 最終要約のプロンプトは、この変更の前と同じである

### Requirement: 祖先のファイルの抽出失敗も部分失敗として数える

祖先のファイルの Stage-1 抽出の失敗は、表示中の小説のファイルの失敗と同じ扱いにしなければならない（SHALL）。失敗したファイルは記録したうえで、残りのファイルの抽出を続ける。失敗ファイル数には祖先のファイルを含める。1件でも失敗があれば、最終要約を生成せず、スナップショットも保存しない。連続失敗による打ち切りは、表示中の小説と祖先を通した連続回数で判定する。

#### Scenario: 祖先のファイルだけが失敗した
- **WHEN** 表示中の小説のファイルはすべて抽出でき、祖先のファイルが1件失敗する
- **THEN** 解析は失敗ファイル数1の部分失敗で終わり、スナップショットは保存されない
