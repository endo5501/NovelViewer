# Spec Delta

## ADDED Requirements

### Requirement: 祖先のファイルの事実は祖先自身のキャッシュに置く

解析で祖先のファイルを Stage-1 抽出するとき、システムは、そのファイルのキャッシュを、祖先自身の `novel_data.db` の `fact_cache` で参照・保存しなければならない（SHALL）。表示中の小説の `fact_cache` に、祖先のファイルの行を書き込んではならない（SHALL NOT）。

キーは `(word, file_name, model_id)` で、`file_name` は祖先のフォルダ内のファイル名とする。有効性の判定（内容ハッシュ、プロンプトのバージョン）と、保存の条件（構造化された空でない結果だけを保存する）は、表示中の小説のファイルと同じ規則に従わなければならない（SHALL）。

この規則により、ある祖先について保存された事実は、その祖先自身を直接解析するときにも、同じ祖先を持つ他の小説を解析するときにも、再利用されなければならない（SHALL）。

#### Scenario: 祖先の抽出結果は祖先のDBに保存される
- **WHEN** 『第2部』の解析で、祖先『第1部』の `003_ch.txt` を「アリス」についてモデル M で抽出する
- **THEN** 『第1部』の `novel_data.db` の `fact_cache` に `(アリス, 003_ch.txt, M)` の行が保存される
- **AND** 『第2部』の `fact_cache` に、この行は保存されない

#### Scenario: 兄弟の作品でキャッシュが共有される
- **WHEN** 『第2部』の解析で『第1部』の「アリス」の事実がキャッシュされた後、同じく『第1部』を参照元とする『外伝』で、同じモデルで「アリス」を解析する
- **THEN** 『第1部』のファイルは内容が変わっていない限り再抽出されず、キャッシュの事実が使われる

### Requirement: 語の削除は祖先のキャッシュに及ばない

表示中の小説で語の要約をすべて削除したとき、削除してよいのは、その小説自身の `fact_cache` にあるその語の行だけである（SHALL）。祖先の `fact_cache` の行を削除してはならない（SHALL NOT）。祖先の行は、祖先自身や他の小説の解析と共有されているためである。

#### Scenario: 子で語を削除しても祖先の行は残る
- **WHEN** 『第2部』で「アリス」の要約を削除する
- **THEN** 『第2部』の `fact_cache` の「アリス」の行は削除され、『第1部』の `fact_cache` の「アリス」の行は残る
