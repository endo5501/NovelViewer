## MODIFIED Requirements

### Requirement: 事実タブのファイル別表示

「事実」タブは、対象単語の `fact_cache` 行を `FactCacheRepository.findForWord` で取得し、ファイル（`file_name`）ごとに区切って事実テキスト（`facts`）を表示しなければならない（SHALL）。各ファイルの見出しには `file_name` を表示する。表示はファイル名の昇順とし、同じファイル名の行が複数ある場合は名乗りの昇順で並べなければならない（SHALL）。Dart の `sort` は安定でないため、第二の鍵がなければ再描画のたびに順序が入れ替わりうる。`fact_cache` に対象単語の行が1件も存在しない場合は、空状態メッセージを表示する。

同一の `file_name` に対してモデルの名乗り（`model_id`）が異なる行が複数存在しうるため、各見出しには `model_id` をバッジとして併記しなければならない（SHALL）。名乗りが見えなければ、読者は同じファイル名が並ぶ理由を判別できない。バッジは既存の「無効」バッジと同じ表現を用い、名乗りを解釈も加工もせずに扱う。

名乗りは長くなりうる（OpenAI 互換のエンドポイントは複数階層のパスでモデルを名指すことがある）。バッジは見出しの幅を越えて隣を押し出してはならず（MUST NOT）、収まらない場合は省略して表示し、完全な値は別の手段（ツールチップ等）で参照できなければならない（SHALL）。

#### Scenario: 複数ファイルの事実を表示

- **WHEN** 単語「アリス」に対し `fact_cache` に `001_ch.txt` と `002_ch.txt` の2行が存在し、ユーザーが詳細ダイアログの「事実」タブを表示する
- **THEN** `001_ch.txt`・`002_ch.txt` のそれぞれの見出しの下に、対応する `facts` テキストが表示される
- **AND** ファイルはファイル名昇順で並ぶ

#### Scenario: 同一ファイルのモデル別の行を見分けられる

- **WHEN** 単語「アリス」の `001_ch.txt` に、名乗りの異なる2つの行（M1 と M2）が存在し、「事実」タブを表示する
- **THEN** `001_ch.txt` の見出しが2つ表示され、それぞれに M1・M2 のバッジが付く
- **AND** 各見出しの下にはその名乗りの行の `facts` が表示される

#### Scenario: 同じファイル名の行は名乗り順に並ぶ

- **WHEN** 単語「アリス」の `001.txt` に名乗りの異なる2行が存在し、名乗りの降順で渡される
- **THEN** 「事実」タブでは名乗りの昇順で並ぶ

#### Scenario: 長い名乗りが見出しを溢れさせない

- **WHEN** 名乗りが見出しの幅に収まらない長さの行を「事実」タブに表示する
- **THEN** レイアウトは溢れず、ファイル名は引き続き表示される

#### Scenario: 事実が存在しない単語

- **WHEN** 対象単語に対する `fact_cache` 行が1件も存在しない状態で「事実」タブを表示する
- **THEN** 事実が無い旨の空状態メッセージが表示される
